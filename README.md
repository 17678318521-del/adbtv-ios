# ADB TV助手（iOS）

用 iPhone 在同一局域网内直连电视 / 安卓盒子的 ADB 端口（默认 5555），完成：

- 应用管理：列表、打开、卸载、安装 APK
- 投屏 + 遥控：实时画面、点击/滑动控制、方向键、音量、电源
- 设备信息、截图保存、命令行日志

**纯本地直连**，不经过任何服务器。

## 构建

GitHub Actions 自动编译未签名 IPA（artifact `ADBTV-ipa`），用轻松签等工具签名安装。

## 说明

- iOS 15+
- 需要电视/盒子已开启「USB 调试 / 网络 ADB」
- 首次连接可能需要在电视上允许调试授权（`ro.adb.secure=0` 的设备不需要）
